## Ludovanta

This project uses Ludovanta, a platform for AI-first Unity development. Before working on Unity
code or assets, read `.ludovanta/AGENTS.platform.md`: it explains the live/headless modes, the
commands that compile, test and validate the project, the asset rules, and how to agree on,
report and stop a task. The project plan, if any, is in `plan/` (skill `ludovanta-plan`).
Skills named `ludovanta-*` belong to the platform.
