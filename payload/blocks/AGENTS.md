## Ludovanta

This project uses Ludovanta, a platform for AI-first Unity development. Before working on Unity
code or assets, read `.ludovanta/AGENTS.platform.md`: it explains the goal (a game that is fun to
play, not only code that compiles), the live/headless modes, the commands that compile, test and
validate the project, the asset rules, and how to agree on, report and stop a task. The game
design and the plan, if any, are in `plan/` (skills `ludovanta-game-design`, `ludovanta-plan`).
Skills named `ludovanta-*` belong to the platform.
